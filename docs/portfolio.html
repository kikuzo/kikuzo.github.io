01分散コンピューティング

さくらインターネット研究所 / 研究構想・技術検討

超個体型データセンターと
エッジ・Fogコンピューティング

クラウドから実世界に分散する計算資源までを連携させ、有機体のように動作する「超個体型データセンター」を構想。集中型と分散型の利点を組み合わせ、コンピューティングを社会の中で利用できる環境を目指しています。

取り組み
エッジの領域・機能による分類、研究開発プランの整理、Fogテストベッドの検討。近年は、自然由来エネルギーの変動に応じたワークロード移動を想定するシステムを検討しています。
公開成果
研究構想・技術的課題の整理、テストベッドに関する発表、研究の進捗報告。
Edge / Fog分散システムワークロード移動エネルギー

02通信ミドルウェア

さくらインターネット研究所・他大学等との共同研究 / 公開資料 2022年

Elixir / NervesとDDSによる
分散通信ミドルウェア「BDDS」

クラウド・エッジ・エンドを統合して利用するアプリケーション実行環境に向け、関数型言語Elixirと組み込み環境NervesにDDS（Data Distribution Service）を組み込む実装を検討しました。

取り組み
ドメイン内での直接通信を実現するミドルウェアの実装と、エッジ・Fog型の実行環境への適用検討。
研究の背景
NICT Beyond 5Gシーズ創出型プログラムの共同受託研究「関数型パラダイムで実現するB5G時代の資源透過型広域分散コンピューティング環境」の一環。成果の一部はNICT委託研究04001によるものです。

03データ流通・スマートシティ

NEC × さくらインターネットの共同実証 / 2018–2022年

FIWAREによるデータ流通実証と、
